# Security Policy

## Reporting a vulnerability

If you find a security issue in sass-walkthrough, please report it privately rather than opening a public
issue. Use GitHub private vulnerability reporting:
<https://github.com/zachshallbetter/sass-walkthrough/security/advisories/new>

Include a description of the issue and its impact, steps to reproduce (a minimal example is
ideal), and the affected commit or version.

This project has a solo maintainer. Handling is best-effort with no SLA: there is no guaranteed
response time, and fixes are prioritized by severity as time allows.

## Scope

sass-walkthrough is a small Sass learning project that compiles SCSS to static CSS. It has one
development dependency (`sass`), runs no server code, and handles no user data. Reports about the
build setup or the published page are in scope.

## Supported versions

Only the latest commit on `main` receives fixes. The project does not publish versioned releases.
